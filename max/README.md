# Max entry point

Open **`QMW_SPAT_MASTER_CONTROL_ROOM.maxpat`**.

That patch is the canonical control room for the current QMW instrument. The numbered
patches in this directory are retained as generated modules and development history;
you do not need to choose among them for normal use.

See `QMW_SPAT_MASTER_CONTROL_ROOM_README.md` for the signal path and rebuild command.
